# T01 评分明细与原文核对

日期：2026-10-21（北京时间）。本轮完成评分契约与确定性核对实现，并用本地替身、隔离数据库及旧输出回放检查。T01业务质量继续待验收。

## 已实现

### 评分由五轴计算

每次评分返回 `itemType`、`dimensions`、`noise`、`evidence` 四字段。五轴必须为0至10整数；旧的单字段总分和额外字段均不接受。后端计算：

`floor((rel×30 + impact×25 + act×20 + info×15 + cred×10) / 10)`

再应用既有噪声上限：菜谱10、一般营销／日程35、无证据或材料不足30；营销限制act≤2、info≤3，合集限制info≤3。总分仍独立计算两次，按原60／65／76门槛判断入选。

依据须连续命中实际发送的标题或正文之一，最多600字符，至少含12个字母、数字或汉字；空依据、过短依据、标题正文拼接和未命中的依据均按材料不足上限处理。该检查确认出处与最低长度，评分理由是否充分仍需业务审阅。

现有 `analyses.output.scoreJudgments` 保存类型、原始及约束后的五轴、原始及有效引文、加权分、上限和最终分；原始模型回答仍在回执中。没有新增数据库字段或迁移，也没有增加模型步骤。

### 主体、产品与数值核对

- 已登记主体ID与实体标签须命中原文别名。不命中时移除；未知机构保留文字原名，不自动挂相近ID，也不自动补另一个ID。
- 蛋品资料没有明确肉类词时移除肉类标签；新城疫资料没有明确禽流感词时移除禽流感标签。混合报道保留有原文支持的词。
- 显式金额与重量通过十进制字符串换算为同币种、同量纲数值。支持本轮错例涉及的葡语小数／倍率、英文千分位、吨／千克及中文万／亿等形式，不进行汇率换算。
- 事实标题、动作、对象和条件文字出现未对应数值时，结构事实置空；标题／摘要／推荐理由出现未对应数值时，中文展示文案清空，相关性为`unknown`，不入选。产品与病种误写同样记录。原回答及内部核对明细保留，正确摘要可以独立保留。

行业规则位于 `industry/quality.ts`，五轴权重及上限位于 `industry/selection.ts`；通用执行位于 `packages/backend/src/editorial/{scoring,quantities,grounding}.ts`，由 `analyze.ts` 接入。
