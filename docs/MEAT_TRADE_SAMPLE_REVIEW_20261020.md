### 正文错配证据

[美国免税牛肉配额稿](https://www.frozengoods.com.hk/zh-CN/news/6897?cate=126&child=8)的 HTML title 与目标标题一致，抽取正文却为畜牧业“十五五”规划问答。[鸡肉净出口稿](https://www.frozengoods.com.hk/zh-CN/news/6848?cate=138&child=4)、[9 月 13 日猪价稿](https://www.frozengoods.com.hk/zh-CN/news/6890?cate=126&child=10)抽取出相同的规划问答，正文哈希三者一致；另两页分别取到猪价／蛋鸡行情和食品安全法草案内容，同样与目标文章主题不符。

这是实际抽取结果错配；本轮未确定是页面结构、推荐区域权重或其他原因，已列入 T06。原 HTML 和正文核对记录保留，尚未修改通用抽取器。

## 已确定的接入顺序

1. **优先核 Mysteel 与优顶特的内容获取路线**：先确认准确账号、可用原文及适用使用条件，保留数据、观点和政策原出处。
2. **冻品e港只对免费贸易资讯设计限量接入**：付费周报不进入普通新闻回填；进一步核列表选择器、日期与去重，免费稿来源保留。
3. **冻品行情先取微信原文**：目前的转载页错配先定位，账号名与原始 ID 核对后再选择路线。
4. **BTC 留作进口牛肉专题**：取得近期原报告／文章后再补本轮缺口。
