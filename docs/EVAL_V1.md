## 模板与后续扩样

industry/gold.example.jsonl 是 20 条明确标为“合成案例”的契约与业务边界模板：14 开发样例、6 留出样例，包含菜谱、名单伪新增、药品、参展不等于采购、疫情不等于禁运、餐饮大宗采购与材料不足。它与上游 eval-selection.ts 格式兼容，但不是已采集真实新闻、不是用户确认金标，也不能用于宣称准确率或调正式门槛。

真实标注：从实际源分层采 100 至 200 条，至少包含中文、日文、葡文、英文，以及日本准入、MENA 采购、贸易数据、企业动作、风险、硬负样例；按事件分组拆开发／留出，防同事件重复泄漏。人工填写 gold.decision 和独立业务审查；事实范围审查模板见 industry/eval.review-template.json。

在具备隔离测试库、模型凭据和预算时，使用上游脚本：

```powershell
node --env-file=.env scripts/eval-selection.ts --gold .data/gold.jsonl --split development --label poultry-v1 --no-import
node --env-file=.env scripts/eval-selection.ts --gold .data/gold.jsonl --split holdout --label poultry-v1-holdout --no-import
```

--no-import 只禁止导入后台，不免除模型调用、回执数据库和费用。未提供凭据时不运行真实评测。先看误判类型，再改提示词；最后才扫描和选择 threshold。保留 T1 60、T1_5 65、T2 76 暂定门槛。

建议验收门槛，尚未测得：精选查准率 ≥85％、高风险／准入召回 ≥90％；明确菜谱等硬噪声不能进精选；工厂、产品范围、日期、采购身份、疫情与禁运不能无证据强化。分别报告总体及各市场／语种／类型的 precision、recall、失败率、成本和耗时。任何缺正文、日期或原文条件的误判单独审查。

本次自动测试只证明格式、状态机、词表、排版与安全边界能执行；不证明真实模型判断能力。归组和综述质量继续使用上游 docs/grouping.md 与 story-digest-evaluation.md 的流程。
