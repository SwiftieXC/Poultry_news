# V1 分类、标签与主题

唯一运行词表：industry/taxonomy.ts；主题：industry/topics.json。分类 key 与主题 slug 为稳定公开身份，部署后不随便改名。

## 一级分类

- `regulation_access`：政策与准入。准入、工厂注册、卫生证书、检疫、Halal、关税、禁运和恢复准入。官方限制公告优先归本类；单纯发现疫情归疫情与风险。
- `trade_flow`：进出口数据。有来源和统计期的进出口量、金额、份额与流向变化。市场预测不当成实测贸易，报价不当成进出口量。
- `market_demand`：市场与需求。消费、产品规格、渠道需求和市场规模的证据。具体买家采购动作归客户与渠道；单店菜品上新不收。
- `competitor`：企业与竞争。企业出口、扩产、投资、新工厂、新产品、并购与合作。核心为企业动作；具体采购归客户与渠道，宏观供应归供给与价格。
- `buyer_channel`：客户与渠道。进口商、经销商、冷链、零售、餐饮集团的采购、招标、供应商调整及渠道动作。参展和企业目录不等于采购。
- `supply_price`：供给与价格。巴西、泰国等产量、库存、供应量、报价与成本变化。标清币种、单位、贸易条件与市场；不把不同价格口径直接比较。
- `biosecurity_risk`：疫情与风险。禽流感、食品召回、残留、食品安全和物流中断。疫情不自动等于禁运；已有进口限制公告按政策与准入分类。

## 维度与上限

2026-10-21校验契约：评分逐次保留内容形态、rel／impact／act／info／cred五轴0至10整数、噪声类型和连续原文依据；后端复算总分，再应用原有菜谱10、一般营销／日程35、无证据／材料冲突30等上限，以及营销act≤2、info≤3、合集info≤3。依据须连续命中发送的标题或正文之一，至少含12个字母、数字或汉字，没有有效依据时按材料不足上限处理。权重30／25／20／15／10与门槛60／65／76不变。

事实字段校验按原始标题和正文命中已登记机构别名；未知机构保留原名，不能改挂相近ID。明确只有蛋品的资料删除肉类标签，新城疫与禽流感分别核对。可识别的金额／重量转换必须与原文同币种、同量纲数值等值；错误结构事实置空，原回执保留，正确摘要可保留。摘要自身数值无法对应原文时进入内部待核对状态，不进入精选。校验不推断未披露的政策范围、主体职责或不同统计期关系。

2026-10-21 主人确认继续T01修订，以下口径接续最新人工标签，优先于下述2026-10-12的经营偏好：禽肉同行的具体新品、经销商订货安排和销售动作，重点市场／竞争供给的可比产量及加工冷链能力，实际禽肉采购，均按已披露的经营事实评价。禽业相邻产品中的蛋及蛋制品实际进出口数据纳入；单纯营养、节庆和育种营销继续排除。已解除禽肉进口暂停、正式恢复市场通道按政策状态变化评价，历史贸易量小不直接抵消其准入信息价值；日本渠道扩源优先级仍后移。原有禁令被重述而无新变化时留作背景。

单个门店的小规模禁止品处置、企业节能宣传和内部车辆替换一般为背景；是否影响规则、供应、成本或渠道须有具体证据。评分五轴、权重、噪声上限、T1／T1_5／T2门槛保持原值。

可行动性包含可直接用于供需、产品与竞争比较的决策对象，不局限于仍可投标的采购窗口；影响程度按对应企业、产业区域和市场的实际覆盖判断。蛋品没有精确产品标签时保留进出口分类、国家和机构，不能用禽肉代替。机构身份逐全称对应，农林水产省、厚生劳动省及动物检疫所分别匹配。五轴解释、权重与门槛遵循现行提示词；具体开发版本与未达标问题见 [T01修订报告](T01_REMEDIATION_20261021.md)。

主体ID及病种标签是事实字段，必须逐项匹配材料中的身份和疾病；词典未收录的机构在事实中保留原名，subjects留空。效率改善与新增实体产能、食品制品与副产品分别标注。日期保留绝对年月及政策阶段；写作以可核实事实和具体跟进对象为主，省去无必要的否定性补充。

2026-10-12 使用者标注后的编辑方向：日本以中国禽肉制品业务关联为优先，缺少产品／工厂／进口商／竞争供给关联的小规模原料禽类限制可留背景；进口商真实交流具有渠道阅读价值，仍不等于采购。MENA 食品进口执法按食品总体口径表达，不机械要求禽肉关键词，也不改成禽肉统计。分类词表不变，详见 [人工标注](LABELING_V1.md) 。这属于经营范围与阅读优先级，不代表当前法律准入判断。

国家作为 TOPIC_TAGS，主题使用原生 field group；界面称“市场与产品”。中国是出口基准，日本、沙特阿拉伯、阿联酋、埃及是重点市场，巴西、泰国是竞争供给，全球为跨国议题。标签只标正文证据支持的国家，不根据域名自动推导流向。

产品种类、加工形态、部位分别存在词表。模型最多输出 6 个 tags（最终管线可能追加已核验主体标签），首位必须为分类标签，其余优先目标市场、原产国、具体形态、事件信号，再实体。避免泛称与具体品类重复占位。例如 [政策与准入、日本、中国、熟制禽肉、新增准入、工厂注册]；主体公司放 subjects，不再重复标签。

Signal Tags 覆盖准入、标准、贸易量、价格、供给、企业、采购、疫情与潜在商机。“潜在商机／风险信号”是有条件的阅读判断，不是交易建议或自动合规结论。禽流感不能自动添加“禁运”；企业扩产不能自动添加“采购”；参展不能自动添加“采购／招标”。

Entity 包含中国重点同行、国际竞争企业和机构；稳定 id＋别名用于 subjects 和 company 主题。Seara 属于 JBS 身份，不能与 BRF 混淆；AQS 与 MAFF 不通过同一域名强制合并。未知买家保留原文名称在标题／事实中，不伪造 entity id，后续经确认再扩充名录。

8 个 Item Types：regulation、official_data、company_action、buyer_signal、market_signal、disease_alert、industry_analysis、general_news。类型由内容理解保存，首页分类由 structure 步骤决定，二者不强行一一绑定。

不保留模型发布、论文、AI 开源等示例标签；RELEASE=null，不出现“新模型”统计。V1 不提供任意多标签 AND／HS 统计筛选承诺；只有原生分类、标签、主题和文本检索。
